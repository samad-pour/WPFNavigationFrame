# WPFNavigationFrame

Ein Visual-Studio-Projekt zur Einführung in die Navigation zwischen verschiedenen Seiten innerhalb einer WPF-Anwendung mithilfe des Frame-Steuerelements.

## Beschreibung

Das Projekt **WPFNavigationFrame** beschäftigt sich mit den Grundlagen der Seitennavigation in Windows Presentation Foundation (WPF). Im Mittelpunkt stehen die Verwendung des Frame-Steuerelements, die Darstellung verschiedener Seiten und die Navigation innerhalb einer grafischen Benutzeroberfläche.

## Funktionen

- Navigation zwischen verschiedenen WPF-Seiten
- Verwendung des Frame-Steuerelements
- Darstellung unterschiedlicher Inhalte innerhalb eines Fensters
- Wechsel zwischen Ansichten ohne Öffnen zusätzlicher Fenster
- Grundlagen der ereignisgesteuerten Navigation

## Technologien

- Microsoft Visual Studio
- C# / .NET
- Windows Presentation Foundation (WPF)
- XAML

## Installation und Ausführung

1. Repository klonen:

   ```bash
   git clone https://github.com/samad-pour/WPFNavigationFrame.git
   ```

2. Die Datei `WPFNavigationFrame.sln` in Visual Studio öffnen.
3. Das Projekt erstellen.
4. Die Anwendung mit `F5` starten.

## Ziel

Das Projekt dient dem Verständnis der Seitennavigation innerhalb einer WPF-Anwendung. Dabei werden grundlegende Konzepte der Navigation mit dem Frame-Steuerelement, der Strukturierung verschiedener Ansichten und der Entwicklung navigierbarer Benutzeroberflächen mit XAML kennengelernt.
